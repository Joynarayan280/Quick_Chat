# 🚀 QuickChat - MERN Real-Time Chat Application

A modern real-time chat application built with the MERN Stack, Socket.IO, Cloudinary, and JWT Authentication.

## ✨ Features

- 🔐 User Authentication (Login & Signup)
- 👤 Profile Update
- 🖼️ Profile Image Upload (Cloudinary)
- 💬 Real-Time Messaging (Socket.IO)
- 🟢 Online/Offline User Status
- 🔒 JWT Authentication
- 📱 Responsive UI
- ⚡ Fast and Modern Interface

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO

### Other Tools
- Cloudinary
- JWT
- bcryptjs

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Joynarayan280/Quick_Chat.git
```

### Backend

```bash
cd server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file inside the `server` folder:

```env
MONGODB_URI=
JWT_SECRET=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
PORT=5000
```
